# MarkShare is an invite-only writing club with public Share Links

Anonymous publishing would make MarkShare an open image host the operator cannot attribute. End-to-end encryption would hide illicit uploads from the operator. A local-only store cannot serve a Share Link. Clerk would add a second identity system beside Instant.

Creators sign in with Instant magic codes. The operator maintains a Creators list. Share Links stay public and read-only. Edit is a named grant to a specific Creator. Instant stores plaintext so the operator can inspect and delete.

**Considered options**: encrypt every Document; optional passwords (MDShare); Clerk invite-only; browser-only storage.

**Consequences**: Wipe anonymous Instant data before this model goes live. `/e/` Edit Links go away. The operator invites people out of band; Instant emails a code only when they sign in.
