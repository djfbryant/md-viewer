# MarkShare

A private writing club for Markdown. Invited authors write; anyone with a Share Link can read.

## Language

**Document**:
A Markdown note MarkShare stores, with a title, optional pasted images, and optional expiry.
_Avoid_: post, page, paste, file, share (as a noun for the note)

**Creator**:
A person the operator has invited to write. Email is their name in the product.
_Avoid_: user, member, account holder, author (except when meaning the owner of one Document)

**Operator**:
The one person who invites and revokes Creators and can delete any Document.
_Avoid_: admin, owner (except Document owner)

**Owner**:
The Creator who created a Document. Only they may grant editors, change expiry, or delete it.
_Avoid_: author, admin

**Editor**:
A Creator the Owner has granted the right to change that Document's markdown and images.
_Avoid_: collaborator, co-author, invitee (invitee means invited to the club, not to a Document)

**Share Link**:
The public, read-only URL for a Document. Anyone who has it can read. It does not grant edit.
_Avoid_: Edit Link, permalink, public link

**Writing club**:
The closed set of Creators. There is no anonymous publishing.
_Avoid_: team, organization, workspace, tenant
